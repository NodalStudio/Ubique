Check stability: move a regression

Click inside the plot to add a point. The line and residuals update together. Add a trillion to the x coordinates to exercise the numerically stable, centered fit.

const fit = linearreg(y, x);
fit.beta;   // slope
fit.alpha;  // intercept
fit.rsq;    // R²
fit.fun(x); // stable prediction
The graph displays coordinates before the offset. R² is undefined for a constant response; a constant predictor is rejected.
